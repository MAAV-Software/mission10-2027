# Contributing

Please open a [pull request](https://help.github.com/articles/using-pull-requests/) to contribute major features. In brief:

1. [Fork](https://help.github.com/articles/fork-a-repo/) this repository
2. Keep your fork [synced](https://help.github.com/articles/syncing-a-fork/) with upstream to make sure your changes don't conflict with someone else's work.
3. Write your code changes
4. Test your code changes. Depending on the subsystem, this might involve Gazebo/SITL, ROS, pytest, etc.
5. Send your pull request with a clear commit message.
